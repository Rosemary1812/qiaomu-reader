# EPUB 引擎接入修复与验收

2026-09-09，本地 4.2.0 修复构建，分支 `codex/fix-epub-regressions`。未提交或发布。

## 修复

- EPUB 关闭与切书使用引擎 CFI、fraction 保存位置，不再用空的旧分页器将进度改成 0%；未完成的加载不覆盖已存位置，迟到回调不能更新另一册书。
- EPUB 搜索使用当前 foliate-js 的 `section.createDocument()`，将摘录对象转换为可读文本；清空或替换搜索会取消旧结果。
- AI 当前页上下文读取引擎的可见正文与章节，保留 6000 字上限；工具栏名称与能力状态随引擎更新，图片封面也不再误报 PDF 错误。
- 引擎位置回调同步更新底栏章节、百分比、顶部进度条和跟随阅读的 AI 来源。
- 构建时将 Foliate 自定义元素隔离到插件和锁定依赖对应的名称；重复加载同一依赖复用注册，依赖更新使用不同名称，避免热重载或其他插件的旧元素注册冲突。
- 关闭阅读器释放引擎；引擎自身处理窗口重排，旧分页器不再留下加载遮罩。移动阅读弹窗也跳过旧分页重建。
