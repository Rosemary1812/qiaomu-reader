# 选文操作与右键菜单验收

2026-09-09，本地修改，未提交、推送或发布。

## 行为

- 浮条顺序为「划线 ▾ / 批注 / 问 AI / 复制 / 更多」。划线沿用上次颜色，颜色菜单保留黄、绿、粉三种。
- MOBI/EPUB 的 iframe 和 PDF/旧分页阅读区共用右键菜单及操作函数；菜单保存原选区和书籍身份，失去原生选区或切换书籍不会把操作写到另一书。
- 更多提供复制引述、复制位置链接、新建摘录笔记、已启用的翻译；已有划线另有删除。含批注时明确显示「删除划线及批注」。
- 同一 CFI 或同一块内选区复用已有记录；点击已划线文字打开操作浮条，换色不丢失批注。划线/换色/删除提供短暂撤销。
- 批注在选区附近编辑，普通 Enter 换行，Cmd/Ctrl+Enter 保存。通过临时 Obsidian 键盘作用域避免宿主抢占；退出、切书及关闭阅读器均释放作用域。
- 批注草稿在插件会话内按书籍与位置保留，最多 100 条；不会跨应用重启保留。保存成功才清除草稿。
- 问 AI 仅带入选文和书籍，不发送问题；未配置时打开 AI 设置。复制直接复制原文。
- 鼠标拖动结束后显示，点击空白关闭浮条的那一次点击不会翻页；移动布局将浮条停靠下方，避开原生选区菜单。
- 顺带修复真实运行日志中定位到的 MOBI 专注阅读错误：引擎书籍不再调用没有正文容器的旧分页器。

- 实际选中文本后浮条宽度约 304px，完整显示六个按钮（含独立颜色箭头），白色表面与正文区区分。
- iframe 右键弹出 macOS 原生菜单，无障碍树确认划线、批注、问 AI、复制、复制引述、复制位置链接、新建摘录笔记及三种颜色。共享回调的选区恢复另有自动测试。

- 本轮真实选文验收以桌面 MOBI 为主；没有宣称 iOS/Android 真机或全部 PDF 类型已通过。
- 没有发送真实 AI 请求，本轮验证的是选文上下文与不自动发送的交互。
- 重载时宿主仍记录 ResizeObserver 的未投递通知；不将本次 UI 验收当作长期内存稳定性证明。旧专注阅读 TypeError 的触发路径已修复并补充回归测试。
