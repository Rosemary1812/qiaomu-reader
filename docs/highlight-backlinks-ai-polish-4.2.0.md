# 划线回跳与 AI 助读界面修复

2026-09-09，本地 4.2.0 修复构建，未提交、推送或发布。已安装到「乔木阅读演示」及 QA 库。

## 问题与实现

- MOBI/EPUB 引擎划线保存 CFI，但列表点击仍查旧分页器的 block 和 DOM span，导致「未找到这条划线」。桌面和移动阅读器现在通过引擎跳到 CFI，并重新绘制对应高亮。
- 笔记导出也只为 block 生成链接，导致 CFI 划线没有回跳入口。普通摘录、自动同步与批量导出共用链接构造器，链接包含 vault、book、highlight 和 CFI；旧 block/PDF 页码路径保留。参数逐一编码，包括会截断 Markdown URL 的 CFI 括号。
- 协议处理等待目标书加载完毕，针对实际打开的视图定位；新请求覆盖旧请求；划线记录删除后仍可用链接中保存的 CFI 返回原文。无效定位会报告失败。
- 旧笔记升级只给精确匹配的已生成摘录行补链接，保留用户改写、批注、标题及已有链接；相同文本存在多个候选位置时不猜测。升级在书库就绪后执行，避免启动初期笔记元数据/插件实例尚未准备好；完整 Markdown 路径也可直接解析。
- AI 消息和来源卡改为宿主中性背景，输入框边框和阴影减弱；快捷提示词移到输入框外上方。发送按钮采用中性色，停止按钮使用浅灰底与清楚的方形图标。旧实现请求了未定义的 square 图标，本轮补齐并加入可见图标回归检查。

## 设计依据

[Carbon 聊天模式](https://carbondesignsystem.com/community/patterns/chatbot/usage/)区分用户消息、回复、结构化选择与输入区域。本轮据此保留各区域职责，将快捷提示词作为输入框上方的辅助动作。

[Carbon 按钮规范](https://carbondesignsystem.com/components/button/usage/)建议区分动作层级，危险按钮用于可能破坏数据的动作。停止生成会保留已生成内容，因此本插件采用中性停止按钮；这是结合本产品行为的设计判断，不是该规范规定了某一种聊天配色。

## 验证记录

- 使用用户提供的四条《三国演义》MOBI 划线副本，实际点击划线列表四次；每次目标原文均进入引擎可见范围，面板关闭，无「未找到」提示。
- 将阅读位置先移到书中其他位置，再实际点击 Markdown 预览中的四个 obsidian:// 链接，四次均打开正确书籍并显示对应原文。没有只调用内部定位方法替代链接验收。
- 单独的冷启动迁移夹具：4 条旧摘录 → 4 个回跳链接；移除新增链接后与原笔记逐字一致，手写段落与空行均保留。重复补链接无重复项。
- 真实库旧四条摘录链接已补齐，旧原文与批注保留。安装过程中又产生一条新划线，正常同步为第五条带链接摘录；因此不将整个笔记最终哈希描述为完全不变。
- 328px AI 侧栏：快捷提示词位于输入框外上方 8px；侧栏 clientWidth 与 scrollWidth 都为 328，没有横向溢出。浅色消息/停止按钮背景 rgb(246,246,246)；深色停止按钮背景 rgb(40,40,40)、文字 rgb(218,218,218)。停止按钮有可见 SVG 方形与「停止生成」无障碍名称。
- AI 生成态通过 QA 中受控 UI 状态检查，没有为外观验证请求真实模型；现有自动交互测试覆盖取消保留部分回答、草稿、IME 与生成中提示词禁用。
- 165 项测试通过；ESLint 零警告、i18n 1228 键、标准构建、社区构建、安装资产哈希校验和 git diff --check 通过。项目无独立 typecheck 脚本。
- 最终真实 Obsidian 未采集到运行时错误；窗口内容宽度与窗口宽度均为 1512px。本轮未使用视口模拟。未做 iOS/Android 真机验收，PDF 的旧链接路径有自动测试，本轮真实链接点击覆盖 MOBI。
