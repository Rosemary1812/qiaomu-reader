# 4.2.1 发布候选验收

日期：2026-09-09。状态：本地候选通过下述检查；尚未发布，也不能据此认定满足官方目录全部要求。CI 以 PR 当前提交的检查结果为准。

## 本轮修复

- 阅读笔记保存完整仓库路径，避免不同文件夹的同名笔记互相覆盖。旧 basename 链接仅在唯一匹配时继续解析；目标不存在或同名歧义时不跳到另一篇笔记。笔记及文件夹重命名会更新已存路径。不同书申请已关联的同名笔记时创建带序号的新文件。
- PDF 双页显示实际范围（例如“第 1–2/2 页”），避免两页已同时展示却看似停在第一页。损坏书籍清空上一本的章节、进度和已加载标记，保留重试与返回书库。
- 将阅读器与 Foliate 的 ResizeObserver 布局写入合并到下一帧；关闭时取消待执行帧，降低布局反馈循环及已关闭视图的回调风险。
- 按产品约定移除快捷提示词编辑入口，保留固定问题和非中文选文的翻译入口；不删除用户旧配置数据。
- 过滤 Codex 已恢复的 WebSocket 降级诊断，避免当作 AI 正文保存；仅匹配已观察到的特定诊断前缀，不屏蔽一般回答或致命错误。
- 补回继承代码的 MIT 署名及许可，构建产物验证要求该声明存在；README 补充本地 CLI 的访问边界。
