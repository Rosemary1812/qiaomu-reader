## 参考产品与取舍

本轮搜索了微信读书、Apple Books（原 iBooks）与 Readwise Reader 的公开资料，没有操作微信或读取其数据。

| 产品与来源 | 可核实的做法 | 本插件采用的原则 |
| --- | --- | --- |
| [Apple Books Mac 官方指南](https://support.apple.com/en-euro/guide/books/ibks8923126d/mac)；[iPhone 官方指南](https://support.apple.com/zh-cn/guide/iphone/-iphc1af7c57/ios) | 字号、主题和阅读方式有直接入口；字体、行距、对齐等放入自定义排版；Mac 支持按窗口条件显示多列。 | 常用选项易找，细节收进更多设置；保留有效的单/双列与窄窗适配。 |
| [Readwise Reader 官方外观 FAQ](https://docs.readwise.io/reader/docs/faqs/appearance) | Aa 集中外观设置，包括字体、字号、行距、网页端行宽；明暗/自动主题；长文界面强调阅读进度与外观。 | 书内设置以阅读为中心，目标统计不占排版空间，工具栏紧凑。 |
| [微信读书 App Store 官方产品页](https://apps.apple.com/cn/app/%E5%BE%AE%E4%BF%A1%E8%AF%BB%E4%B9%A6/id952059546?platform=ipad) | 腾讯发布的公开介绍突出阅读体验、阅读记录与笔记。 | 保留阅读、摘录、笔记的主要路径。公开介绍不足以核实当前版每一个设置；搜索发现的旧版教程不作为现版控件证据。 |

判断：不照搬竞品的设置数量。每个保留项必须接入当前阅读引擎；没有效果的旧项先撤出界面。白色上下工具栏是本次用户指定的视觉选择，与正文主题分开。

## 改动清单

| 项目 | 处理与原因 |
| --- | --- |
| 原生 Qiaomu Book Reader 标题栏 | 仅在阅读器叶片隐藏，保留插件工具栏与书名；普通笔记的标题栏不受影响。 |
| 上下工具栏 | 桌面高 40px，贴阅读区上下边缘，白底、灰色图标、细分隔线；正文和周围留白统一使用阅读主题。 |
| 字号、字体、行距、对齐 | 样式直接作用到正文段落等文本块，修复 MOBI 自带 align="justify" 覆盖左对齐的问题；保留标题大小、强调和代码字体。 |
| 行距滑块 | input 时直接更新正文，不再只更新设置面板预览。 |
| 跟随 Obsidian | 将宿主实际背景/文字颜色传入章节 iframe，监听宿主 css-change 更新；解决变量无法跨文档继承的问题。 |
| 单/双页、翻页/滚动、主题、翻页按钮 | 保留，真实 MOBI 控件已复测。点击翻页沿用前轮 iframe 导航修复。 |
| 每行字数、页面内位置、翻页动画 | 从书内/全局对应设置入口移除：这些项只连接旧分页器，对现用 Foliate 正文无效。旧数据字段保留，避免破坏已有配置和兼容路径。 |
| 阅读目标与计时 | 不再出现在书内排版的更多设置；保留全局阅读设置和已有计时入口。全局开关立即更新打开的阅读器。 |
| 全局设置同步 | 翻页方式更新打开视图的交互类；重排同时覆盖桌面视图与移动端阅读弹窗。 |

本轮聚焦阅读界面和阅读/外观设置，没有声称逐一实测所有 AI 服务、设备功能或数据管理设置。

## 验证

- 独立 QA 库中使用《三国演义》MOBI 副本，原文件 12,380,270 字节、126 节；实际点击阅读设置中的控件，并读取章节 iframe 的计算样式和分页器状态。
- A+：18 → 19px；朱雀仿宋 → 系统黑体；行距 input=1.5 后计算值 28.5px；右对齐生效。推荐排版恢复左对齐与 1.75 行距（19px 时为 33.25px）。
- 夜间正文背景 rgb(24,26,27)，工具栏仍为白色；上下滚动的 flow=scrolled，左右翻页 flow=paginated；宽窗单页/双页实际列数为 1/2；常驻翻页箭头数量为 2。
- 上述重排始终留在同一章节；排版变化会改变可见范围 CFI，不据此声称逐字视口不变。
- 最终构建切换 Obsidian 明暗主题，自动主题正文背景/文字分别对应 #ffffff/#222222 与 #1c1c1c/#dadada；工具栏保持白色，CFI 不变。首次立即读取遇到主题尚未完成切换，等待完成后复测并连续切换五次，结果一致。
- 安装到用户真实库并重载后，《三国演义》CFI 与安装前完全一致：`epubcfi(/6/30!/4,/26/1:499,/28/1:267)`。标题栏 display=none；上下工具栏白色且高 40px；正文与外围区域均为 rgb(234,240,232)。5 个 Markdown 文件哈希均未改变，未采集到运行时错误。
- 159 项测试通过，ESLint 零警告，i18n 1228 键通过，标准构建与社区构建通过，安装资产哈希校验通过，git diff --check 通过。项目无独立 typecheck 脚本。
- 本轮未做 iOS/Android 真机验收；移动端同步代码不等于真机通过。MOBI 连续翻页与资源回收的前轮验收见 [MOBI 分页记录](mobi-pagination-4.2.0.md)。
